守护常在 Continuous ProtectionIdentity · Poster · Merchandise · Spatial Experience

将“守护”从传统信仰，
转译为可被日常感知的现代体验。

本项目面向 18—35 岁年轻受众，将妈祖文化中的“守护”价值进行当代视觉转译，使其进入社交媒体传播、文创消费与城市文化空间语境。品牌不再依赖传统宗教形象表达，而是通过抽象视觉语言，将“守护”重构为一种可被日常感知的情绪体验与心理安全机制。

Project Type文化品牌视觉系统设计 / Cultural Brand Identity System

Project Overview

文化品牌的当代转译

核心目标是将传统信仰转译为当代青年可感知的“持续守护体验”。因此，品牌视觉策略围绕“不直接复刻传统神像形象”“以象征性女性守护者意象替代具象宗教表达”“将海洋文化符号转化为可组合视觉系统”等方向展开。

Brand Positioning面向年轻受众的文化品牌视觉系统设计，使传统文化进入社交传播、文创消费与城市文化空间。
Core Goal将“守护”从单一仪式行为转化为一种持续存在的心理安全感。
Key Metaphor光 = 指引与确定性；海 = 不确定的现实环境；风 = 外部变化；航行 = 个体成长路径。

Visual Narrative

主视觉与叙事线索

主视觉围绕“光照航路”展开构建，画面以圆形光晕作为中心结构，结合斜向灯塔光束与海浪曲线底纹，形成稳定的视觉系统。主体采用抽象化东方女性守护者意象，仅作为象征性表达，不直接呈现传统宗教神像。

Visual Center圆形光晕作为守护中心，建立强识别视觉锚点。
Narrative Direction灯塔光束与海浪曲线共同构成“被照亮的航路”叙事。
Tone庄重、克制、安静，带有现代东方的精神气质。

Visual System

海浪、光晕与灯塔光束

品牌视觉由三大核心元素构成统一系统：海浪曲线象征现实环境的流动性与不确定性；圆形光晕象征守护中心与精神锚点；灯塔光束象征方向与引导路径，形成视觉动势与叙事线索。

色彩系统以朱红、海蓝、暖金与米白为主，在低饱和、高质感的现代东方语境中建立庄重、克制且富有精神性的视觉气质。

Graphic Elements海浪曲线 / 圆形光晕 / 灯塔光束
Color System朱红：文化记忆；海蓝：空间感；暖金：守护意象；米白：留白与呼吸感
Typography现代宋体 / 几何无衬线英文字体，强调秩序感、留白与阅读清晰度。

Campaign Poster

从海报到品牌传播

品牌视觉延展为“平安、出发、归来、相伴”等统一系列海报。它们共享同一套视觉语法，但通过不同构图变化，呈现个体在不同心理阶段中的守护体验。

Communication Logic统一图形语言 + 明确视觉中心 + 具有呼吸感的版式留白。
Creative Direction强调空间深度与情绪张力，并预留中文标题排版空间。
Use Case海报、社交视觉、文创展示、空间导视与活动传播。

Merchandise & Spatial Experience

文创延展与空间中的守护体验

品牌延伸至祈福卡、御守卡、明信片、香片包装与手提袋等实际生活场景。所有产品统一使用“海浪曲线 + 圆形光晕”作为基础视觉结构，并通过朱红与暖金工艺强化仪式感。

在线下空间中，品牌通过圆形光环入口、光束导视系统、海浪地面纹理、文创陈列与互动祈福区域构建完整的沉浸式守护体验。

Merchandise祈福卡 / 御守卡 / 明信片 / 香片包装 / 手提袋。
Space Nodes圆形光环入口 / 光束导视系统 / 海浪地面纹理 / 文创陈列 / 互动祈福区域。
Experience Result从平面视觉延展到可步行、可参与、可感知的整体文化品牌体验。

Project Summary

项目总结

本设计将妈祖文化中的“守护”概念进行当代视觉重构，通过统一视觉系统（海浪 / 光晕 / 光束）构建可扩展的品牌语言，使传统文化转化为可进入城市生活与数字传播场景的现代品牌体验。
